# Firefly III Tools

Scripts for interacting with Firefly III, an open-source personal finance manager.

## Setup

1. Clone this repository
2. Copy `.env.example` to `.env` and fill in your API details:
   ```
   cp .env.example .env
   ```
3. Install required dependencies:
   ```
   pip install -r requirements.txt
   ```

## Available Tools

### money.py

Interacts with Firefly III API to perform various transaction operations.

#### Usage

```bash
python money.py [action]
```

#### Available Actions

**payback**
- Queries transactions with tag "payback" OR category "vix-events"
- Exports to `data/payback.csv`
- Sorted by date (most recent first)

**search**
- Search transactions by exact amount
- Usage: `python money.py search --amount 123.45`
- Outputs results to console

**category**
- Search transactions by category name
- Usage: `python money.py category "vix-events"`
- Outputs results to console

**list-rules**
- List all automation rules from Firefly III
- Shows rule ID, active status, title, group, triggers, and actions
- Outputs results to console

**untagged** ⭐ NEW
- Query uncategorized transactions from past 3 months
- Uses AI pattern matching to suggest categories
- Exports two files:
  - `data/untagged.csv` - Full transaction details with suggested categories
  - `data/untagged_updates.csv` - Transaction IDs and categories for bulk updates (sorted by category)
- Use `apply_categories.py` to apply the suggested categories

### apply_categories.py ⭐ NEW

Applies suggested categories to uncategorized transactions in Firefly III.

#### Usage

```bash
# Interactive mode (prompts for confirmation)
python apply_categories.py

# Non-interactive mode (auto-confirm)
python apply_categories.py --yes
```

#### What it does

1. Reads `data/untagged_updates.csv` generated by `python money.py untagged`
2. Shows summary of categories to apply
3. Asks for confirmation (unless `--yes` flag is used)
4. Updates each transaction via Firefly III API
5. Shows progress and final summary

#### Supported Categories

The AI categorization currently supports:
- **Debt**: Loan payments, bill payments (LOAN PMT, BILL PMT, WWW PMT)
- **Transfer**: Internal transfers, e-transfers (TRANSFER, TFR)
- **Restaurant**: Dining, cafes, fast food (RESTAURANT, CAFE, SUBWAY, etc.)
- **Grocery**: Supermarkets (SOBEYS, COSTCO, WALMART, etc.)
- **Gas**: Fuel stations (PETRO, IRVING, SHELL, ESSO, etc.)
- **Medical**: Pharmacy, dental, clinics (PHARMACY, DRUG, DENTAL, etc.)
- **Household**: Home goods, hardware (CANADIAN TIRE, IKEA)
- **Entertainment**: Streaming, gaming (NETFLIX, SPOTIFY, STEAM, etc.)
- **Taxi**: Ride-sharing (UBER, LYFT, TAXI)
- **Utilities**: Phone, internet, electricity (EASTLINK, TELUS, BELL, etc.)
- **Clothing**: Apparel retailers (SIMONS, H&M, ZARA, etc.)
- **Software**: Software subscriptions (ADOBE, MICROSOFT, APPLE, GOOGLE)
- **Amazon**: Amazon purchases

## Workflow Example: Auto-Categorize Transactions

```bash
# Step 1: Generate category suggestions for uncategorized transactions
python money.py untagged

# Step 2: Review the suggestions in data/untagged_updates.csv
# (Optional: Edit the CSV to adjust categories)

# Step 3: Apply the categories to Firefly III
python apply_categories.py --yes
```
